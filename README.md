# QA-LEADER — Portafolio de QA Tester

Este repositorio reúne mi progreso y proyectos prácticos durante mi formación como QA Tester. El objetivo es demostrar habilidades de pruebas manuales, APIs, SQL y automatización.

## Contenido

- `casos-de-prueba/`: escenarios, planes y matrices de prueba.
- `reportes-de-bugs/`: defectos documentados con pasos, evidencia, severidad y prioridad.
- `postman/`: colecciones y ambientes para pruebas de APIs.
- `sql/`: consultas de validación de datos.
- `playwright/`: pruebas automatizadas de interfaz web.
- `evidencias/`: capturas, videos y otros soportes de las pruebas.

## Proyecto de práctica

Aplicación objetivo: una tienda web con registro, inicio de sesión, catálogo, carrito y compra.

## Cómo usar este portafolio

Cada módulo incorporará una breve descripción, los archivos de trabajo y un resumen de los aprendizajes. El contenido se actualizará semanalmente durante el plan de estudio.

## Habilidades en desarrollo

- Testing manual y exploratorio
- Diseño de casos de prueba
- Reporte y seguimiento de bugs
- Pruebas de APIs con Postman
- SQL para validación de datos
- Automatización con Playwright y TypeScript
